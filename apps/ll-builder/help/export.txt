Export to linyaps layer, UAB, or UABX
Usage: ll-builder export [OPTIONS]

Options:
  -h,--help                   Print this help message and exit
  --help-all                  Expand all help
  -f,--file FILE:FILE         File path of the linglong.yaml
  -z,--compressor X           supported compressors are: lz4(default), lzma, zstd
  --icon FILE:FILE Needs: --uabx Excludes: --layer
                              UABX icon (optional)
  --layer Excludes: --icon --uabx --loader --output --ref --modules
                              Export to linyaps layer file (deprecated)
  --uabx Excludes: --layer    Export an executable UABX
  --loader FILE:FILE Needs: --uabx Excludes: --layer
                              Use custom UABX loader
  --no-develop Needs: --layer Don't export the develop module
  -o,--output FILE Excludes: --layer
                              Output file
  --ref REF Excludes: --layer Reference of the package
  --modules MODULES ... Excludes: --layer
                              Modules to export
