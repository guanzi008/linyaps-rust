Add a new repository
Usage: ll-cli repo add [OPTIONS] NAME URL

Positionals:
  NAME TEXT REQUIRED          Specify the repo name
  URL TEXT REQUIRED           Url of the repository

Options:
  -h,--help                   Print this help message and exit
  --help-all                  Expand all help
  --alias ALIAS               Alias of the repo name
