Instalando um aplicativo ou runtime
Usage: ll-cli install [OPTIONS] APP

Example:
# install application by appid
ll-cli install org.deepin.demo
# install application by linyaps layer
ll-cli install ./demo_0.0.0.1_x86_64_binary.layer
# install application by linyaps uab
ll-cli install ./demo_x86_64_0.0.0.1_main.uab
# install specified module of the appid
ll-cli install org.deepin.demo --module=binary
# install specified version of the appid
ll-cli install org.deepin.demo/0.0.0.1
# install application by detailed reference
ll-cli install stable:org.deepin.demo/0.0.0.1/x86_64
    

Positionals:
  APP TEXT REQUIRED           Especifique o ID do aplicativo, que também pode ser um arquivo .uab ou .layer

Options:
  -h,--help                   Exibir esta mensagem de ajuda e sair
  --help-all                  Expandir toda a ajuda
  --module MODULE             Instalar um módulo específico
  --repo REPO                 Instalar a partir de um repositório específico
  --force                     Forçar a instalação do aplicativo
  -y                          Responda automaticamente sim a todas as perguntas
  --no-auto-prune             Do not automatically remove unused dependencies

Se encontrar qualquer problema durante o uso,
Você pode reportar erros para o time linyaps sob este projeto: https://github.com/OpenAtom-Linyaps/linyaps/issues
