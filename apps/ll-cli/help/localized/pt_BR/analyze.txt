Analyze installed applications
Usage: ll-cli analyze SUBCOMMAND [OPTIONS]

Options:
  -h,--help                   Exibir esta mensagem de ajuda e sair
  --help-all                  Expandir toda a ajuda

Gerenciando aplicativos instalados e runtimes:
  size                        Show installed module sizes and repository real size
  depends                     Display installed application dependency tree

Se encontrar qualquer problema durante o uso,
Você pode reportar erros para o time linyaps sob este projeto: https://github.com/OpenAtom-Linyaps/linyaps/issues
