Mettre à jour l'adresse du répertoire
Usage: ll-cli repo update [OPTIONS] NAME URL

Positionals:
  ALIAS TEXT REQUIRED         Alias du nom du dépôt
  URL TEXT REQUIRED           L'adresse du répertoire

Options:
  -h,--help                   Imprimer ce message d'aide et quitter
  --help-all                  Développer toute l'aide

Si vous avez rencontré des problèmes lors de l'utilisation,
Vous pouvez signaler les bogues à l'équipe linyaps dans le cadre de ce projet : https://github.com/OpenAtom-Linyaps/linyaps/issues
