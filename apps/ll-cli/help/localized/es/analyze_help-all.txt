Analyze installed applications
Usage: ll-cli analyze SUBCOMMAND [OPTIONS]

Options:
  -h,--help                   Imprimir este mensaje de ayuda y salir
  --help-all                  Expandir toda la ayuda

Gestionar aplicaciones instaladas y tiempos de ejecución:
size
  Show installed module sizes and repository real size
  Options:
    --sort FIELD:{actual,logical,exclusive,shared,id} [actual] 
                                Sort result by specify field. One of "actual", "logical", "exclusive", "shared" or "id"
    --asc                       Sort in ascending order

depends
  Display installed application dependency tree
  Positionals:
    APP TEXT                    Especificar el ID de la aplicación instalada

puede reportar errores al equipo de linyaps en este proyecto: https://github.com/OpenAtom-Linyaps/linyaps/issues
